2. MATHEMATICAL ENGINE & TELEMETRY PARITY (LastbencherOS `sce` Formula)
================================================================================
The attendance calculation engine implements the exact mathematical formulas:
- Total Classes: T = Present + Absent
- Percentage: P = (Present / T) * 100 (or 0 if T = 0)
- Target: TargetPercentage (default 78%, customizable from 50% to 100%)
- Required to Reach Target:
    If P < Target: Math.ceil(((Target/100) * T - Present) / (1 - (Target/100)))
- Bunk Capacity (Safe to Bunk):
    If P >= Target and T > 0: Math.floor((Present - (Target/100) * T) / (Target/100))
